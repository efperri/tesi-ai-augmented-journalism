# Risultati

Salvare qui risultati completi, tabelle, XLS, CSV, grafici e altri output analitici.

Consigli:

- usare nomi file datati o versionati;
- distinguere risultati grezzi, intermedi e finali;
- includere un breve README o dizionario dati per ogni gruppo di output;
- evitare di pubblicare risultati che permettano di ricostruire testi protetti se non consentito.
