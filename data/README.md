# Dati

Questa directory contiene o descrive i corpora usati nella ricerca.

Usare i file README nelle sottodirectory per distinguere articoli giornalistici originali, fact-sheet JSON estratti, articoli generati via ChatGPT, corpus pre-2022 e materiali derivati.

Per ogni elemento inserito, aggiornare `metadata/source_register_template.csv`, `metadata/dataset_manifest_template.csv` ed eventuali note metodologiche in `docs/methodology.md`.
